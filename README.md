# 🛍️ Gen Cart – Fashion E-commerce Website

**Gen Cart** is a modern and responsive fashion e-commerce website designed to showcase trendy clothing, footwear, and fashion accessories.

The website provides a clean shopping interface with attractive product displays, category sections, and a stylish layout.

## 📸 Project Overview

Gen Cart is a fashion shopping website featuring:

- Modern homepage design
- Attractive hero section
- Shop by category section
- Trending products collection
- Product images and pricing
- Special discount badges
- Promotional offer section
- Responsive layout for mobile devices

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design

## 🚀 How to Run the Project

Follow these steps to run Gen Cart on your computer:

1. Clone the repository:

   ```bash
   git clone https://github.com/Vaageeshsingh/gen-cart.git
   ```

2. Open the project folder:

   ```bash
   cd gen-cart
   ```

3. Open `index.html` in your browser.

You can also use the **Live Server** extension in Visual Studio Code for a better development experience.
